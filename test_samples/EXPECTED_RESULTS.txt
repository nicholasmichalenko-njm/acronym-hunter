ACRONYM HUNTER: TEST SAMPLES
============================
All content is fictional ("Kestrel" smallsat program, "Northwind Orbital").
CUI and ITAR markings in the Word file are fake test markings.

DATABASE FOR THESE TESTS
  The app ships with an EMPTY acronym database. These checks (CDR / LEO definition choices, excluded noise
  words) assume the test database: copy test_samples\test_database.csv over acronym_database.csv in a
  throwaway copy of the app folder before scanning. tools\evaluate.py uses it automatically.

HOW TO TEST
  1. Open AcronymHunter.exe.
  2. Click "Scan Folder" and pick this test_samples folder (or "Select Files" for one file).
  3. Compare the table against the checks below.
  A full scan of all 13 files takes about 1 to 3 minutes (OCR is the slow part).
  v1.3.0: about 135 rows. Score 94.1% recall (48 of 51), 6 of 8 known-noise terms still reported.
  Baseline from 2026-10-20 (v1.0.1): about 115 rows, including 2 "Not scanned" rows
  (the corrupt PDF and the linked picture on slide 15 of the large deck).

AUTOMATED SCORING
  ground_truth.csv in this folder lists terms that must be found and noise that must not appear.
  Score the app:  .\venv\Scripts\python.exe tools\evaluate.py --note "what changed"
  v1.0.1 score: 92.5% recall (37 of 40), 6 of 8 known-noise terms still reported. See TRAINING_GUIDE.md.

HOW LOCATIONS READ
  PDF          file (p.7)
  PowerPoint   file (Slide 12) | (Slide 3 notes) | (Slide 10 chart) | (Slide 4 SmartArt) | (Slide 20, hidden)
               file (Slide 12, image 'Orbit Diagram' image2.png)   <- shape name from the Selection Pane + image file
  Word         file (section '1. SCOPE OF WORK', para 2-9) | (Header 1) | (Footer 1) | (Footnotes) | (Comments)
               file (Body, image 'Picture 1' image1.png)
  Excel        file (Risk Register) | (Risk Register shapes) | (Risk Register chart) | (Risk Register comments)
               file (Risk Register, image 'Image 1' image1.png)
  Image        file (Image)
  Vector       file (Vector text)  <- text read straight from the SVG/EMF
               file (Body, image 'Picture 1' image1.emf, vector text)  <- diagram inside an Office file

WHAT TO TRY IN THE APP
  - Status filter "Errors / not scanned": shows the corrupt PDF and the slide 15 linked picture.
  - Select CDR, pick "Critical Design Review", click Apply Choice.
  - Select COPV, type "Composite Overwrapped Pressure Vessel", click Include in DB. Rescan: it shows as Resolved.
  - Select SCOPE, click Exclude. Rescan: it disappears unless "Show Excluded" is checked.
  - Click Export CSV and open the report.
  Note: Include and Exclude change acronym_database.csv in the app folder you are running.


WHAT THE APP CANNOT READ (reported as "Not scanned" rows)
  - Linked pictures (stored outside the file). Fix: re-insert as embedded pictures.
  - Embedded objects (an Excel sheet or Visio drawing inside a slide) are not opened;
    their preview picture is OCR'd when it is a normal image.
