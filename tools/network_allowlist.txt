# Program files that may link Windows networking APIs (ws2_32.dll), with the reviewed reason each is safe.
# Format: path relative to the package folder | reason. Anything not listed fails tools\network_audit.py.
# Files under _internal\tesseract can never be listed: Tesseract must link no networking API at all.
# Reviewed 2026-10-22 for v1.7.0.
_internal\python311.dll | CPython runtime. App startup replaces socket.connect, DNS lookups, and urllib with functions that refuse (network guard, tested)
_internal\_socket.pyd | CPython socket module: the object the network guard patches; every connect and DNS call refuses
_internal\select.pyd | CPython select(): waits on handles; opens no connection
_internal\libcrypto-3.dll | OpenSSL crypto library used by hashlib (SHA-256 checks). TLS module (ssl) is excluded from the build
_internal\lxml\etree.cp311-win_amd64.pyd | libxml2 inside lxml. Office XML is parsed with no_network=True, no DTD, no entities (hardened parser)
_internal\lxml\objectify.cp311-win_amd64.pyd | Same libxml2 build as lxml.etree; not used for network access
_internal\tcl86t.dll | Tcl runtime behind the Tk window. Its socket command runs only from Tcl scripts; the app runs none
_internal\PySide6\Qt6Core.dll | Qt core library (2.59.0, Stationkeeper (Qt)). Links Winsock only for its event loop's socket notifier; it opens no connection itself. The build ships no QtNetwork, and the Python network guard refuses every connect and DNS call
